# Nina Bee — Lead Data Engineer

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. No build step or package installation required.

## Preview and customize

Open index.html in a browser, or serve this directory with any static web server. Edit index.html for content, assets/css/styles.css for styling, and assets/js/main.js for interactions.

The site includes an introduction, biography, engineering focus areas, design principles, an original CSS data-flow illustration, responsive navigation, and a persistent light/dark theme. The contact link uses the repository owner's GitHub profile. Add Nina's email, LinkedIn, résumé, and verified project examples when available.

Copy is introductory positioning for Nina to review before publication. No specific employers, credentials, years of experience, or project results are claimed. Legacy tutorial images, sample Alexa résumé, text reference, and Swiper files remain archived in the repository but are not used by the page. There is no backend or contact form. Google Fonts is optional, with local fallback fonts.

## Deployment

Serve the repository root on any static host. For GitHub Pages, select main and / (root) in the repository's Pages settings. Deployment has not been enabled by this change.
